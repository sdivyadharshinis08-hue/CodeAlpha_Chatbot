# CodeAlpha Chatbot

A simple rule-based chatbot made in Python as part of my CodeAlpha internship.

## How it works
- The user types a message like "hello", "how are you", or "bye".
- The chatbot replies with a predefined answer.
- Unknown messages get a "Sorry, I don't understand that" reply.
- The chat ends when the user types "bye".

## How to run
Open a terminal in this folder and type: python chatbot.py

## Concepts used
if-elif, functions, loops, input/output
